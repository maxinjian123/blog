# 排版要求
1. **标题层级**：梳理 h1-h6 标题层级，保证结构清晰、层级正确（h1 用于主标题，正文内按需使用 h2/h3）。
2. **段落拆分**：将过长的段落拆分为适合屏幕阅读的短段落（每段 3-5 行）；短句过多的可适当合并。
3. **列表与强调**：适合列举的内容使用 ul/ol 列表；关键信息可用 strong 强调，但不要过度使用。
4. **引用与代码**：引用他人内容用 blockquote；代码统一放入 pre/code 并标注语言。
5. **标签规范**：使用语义化标签（p、h2、h3、ul、ol、li、blockquote、pre、code、strong、em），标签闭合正确，行内不留多余空白。
6. **标点规范**：统一中英文标点使用，修正明显错误的标点与多余空格。

# 禁令
- 不新增、删除或改写正文观点与事实，仅做结构排版调整。
- 不要添加"已排版"之类的说明文字。
