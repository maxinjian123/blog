# 排版要求
1. **标题层级**：梳理 H1-H6 标题层级，保证结构清晰、层级正确（H1 用于主标题，正文内按需使用 H2/H3）。
2. **段落拆分**：将过长的段落拆分为适合屏幕阅读的短段落（每段 3-5 行）；短句过多的可适当合并。
3. **列表与强调**：适合列举的内容使用无序列表/有序列表；关键信息可用加粗强调，但不要过度使用。
4. **引用与代码**：引用他人内容用 Markdown 引用块（>）；代码统一放入代码块并标注语言。
5. **空行规范**：标题、列表、代码块前后保留一个空行；段落之间保留一个空行，统一排版间距。
6. **标点规范**：统一中英文标点使用，修正明显错误的标点与多余空格。

# 禁令
- 不新增、删除或改写正文观点与事实，仅做结构排版调整。
- **全文仅使用规定 Markdown 富文本标签排版，彻底禁用所有 HTML 格式、特殊排版符号，全篇使用标准中文撰写。**
- 不要添加"已排版"之类的说明文字。
