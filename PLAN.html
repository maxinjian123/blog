项目概述

OVERVIEW

TechMind Blog 是一个全栈个人博客系统，采用前后端分离架构，覆盖读者浏览、内容管理与 API 服务的全链路需求。深度集成 AI 辅助写作能力，提供文章创作、润色、续写、摘要、标签、封面图生成和评论自动回复等智能功能。

子系统技术栈端口定位
frontend 博客前端Vue 3 + TypeScript + Vite + Tailwind CSS v45173博客读者端，双栏响应式布局
backend 后端服务Node.js + Express + Sequelize + MySQL + Redis3000RESTful API + AI 服务
admin 管理面板Vue 3 + Ant Design Vue 4 + Vite + md-editor-v35174后台管理，Markdown 文章创作

架构决策记录

ARCHITECTURE DECISIONS
决策说明
Ollama + 豆包双驱动Ollama 提供本地推理，无网络依赖；豆包 API 提供云端大模型能力。Ollama 不可用时自动降级到豆包
三种限流方式并存全局 API 用 express-rate-limit；资源级限流用手动 Redis 键检查；自定义场景用 createRateLimit 工具函数
@unhead/vue SEO替代 vite-plugin-prerender (ESM 不兼容)，运行时动态设置 OG/Twitter/canonical
评论 NSFW 检测评论图片上传自动检测 NSFW 内容 (像素级肤色分析)，保障内容安全
SVG 验证码登录使用数学验证码 + Redis 一次性校验，防止暴力破解
评论 QQ 号绑定发表评论使用 QQ 号自动获取昵称和头像，降低垃圾评论风险
游标分页评论列表使用游标分页 (cursor-based)，避免深度分页性能问题
管理面板 Markdown 独占编辑器从双模式简化为纯 Markdown，降低维护成本，统一创作体验
抽屉式编辑器布局元信息面板和 AI 助手改为可展开抽屉，默认隐藏，解决页面拥挤和编辑区遮挡问题
移除 RAG 知识库移除 Chroma 向量数据库依赖，简化系统架构，减少外部服务依赖
